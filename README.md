# CHOKEV — $CHOKEV

Одностраничный лендинг мем-коина. Чистый статический HTML/CSS/JS, без сборки.

**Идея:** Робин Гуд отбирал у богатых и раздавал бедным. Влад взял его за горло и развернул поток.
Кнопка BUY «temporarily unavailable», кнопка SELL работает прекрасно.

## Структура

```
chokev/
├── index.html      — весь сайт (стили и скрипты инлайном)
├── assets/         — вырезанные кропы персонажа + фавикон
└── README.md
```

## Настройка перед листингом

В начале `index.html` блок SETTINGS — три строки:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку
```

Пока `BUY_URL` пустой, кнопка BUY выглядит неактивной и никуда не ведёт.

## Что внутри

- **Гейт** — hold to enter (надо зажать, а не кликнуть).
- **Мини-игра THE GRIP** — держишь кнопку, ведёшь стрелку давления внутри зелёной полосы,
  которая двигается. 8 раундов, каждый открывает карточку в секции WHAT FELL OUT.
- **Убегающая кнопка BUY** — 6 уворотов, потом отдаётся.
- Клик по персонажу сыплет купюры со звоном.
- Музыка — корпоративный лифт-джаз на Web Audio, без аудиофайлов.
